# Windows 개발 환경 자동 설정 요청 프롬프트

아래 전체 내용을 Codex 채팅에 붙여 넣으세요.

```text
나는 개발 경험이 거의 없는 Windows 사용자야. 내가 터미널에 명령을 입력하거나 파일을 직접 고치게 하지 말고, 네가 이 컴퓨터에서 필요한 검사와 설치를 직접 진행해 줘.

목표는 Codex CLI, Git for Windows, GitHub CLI를 사용할 수 있게 만들고 Git 기본 사용자 설정과 GitHub 로그인을 끝내는 것이야. 설치를 시작하기 전에 아래 원칙을 지켜.

- Windows 환경인지, PowerShell을 사용할 수 있는지, winget을 사용할 수 있는지 먼저 확인해. 검사 결과는 쉬운 한국어로 알려 줘.
- 비밀번호, GitHub 토큰, 인증 코드, 개인 키는 나에게 채팅으로 묻거나 채팅에 표시하지 마. 로그인·관리자 권한 창이 나오면 내가 직접 입력하도록 안내해.
- 내게 무엇을 물을 때는 한 번에 하나만 물어. 여러 질문을 목록으로 한꺼번에 하지 마.
- 내가 직접 터미널 명령을 실행하라고 시키지 마. 필요한 명령은 네가 실행해.
- 공식 출처와 신뢰할 수 있는 패키지 관리자만 사용해. 임의의 다운로드 사이트, 출처 불명의 스크립트, 비공식 패키지는 사용하지 마.
- 설치, 업데이트, 설정 실패 시 이미 성공한 도구나 기존 설정을 되돌리거나 덮어쓰지 마. 원인과 안전한 다음 행동을 설명한 뒤 필요한 경우에만 질문해.

다음 절차를 순서대로 진행해.

1. 먼저 `codex --version`, `git --version`, `gh --version`을 각각 확인해. 명령을 찾지 못한 경우와 실행은 되지만 오류가 나는 경우를 구분해.

2. 각 도구의 설치 상태와 최신 버전을 확인해. Git for Windows는 `Git.Git`, GitHub CLI는 `GitHub.cli`의 winget 공식 패키지 정보를 우선 사용해. Codex CLI는 OpenAI 공식 문서에서 현재 Windows 설치 방법을 확인한 뒤 그 방법만 사용해. 설치된 버전과 최신 버전을 쉬운 말로 보여 줘.

3. 도구별로 다음 규칙을 적용해.
   - 설치되어 있지 않으면 설치를 진행해.
   - 이미 최신이면 설치나 업데이트를 건너뛰고 그대로 유지해.
   - 업데이트가 가능하면 현재 버전과 최신 버전을 보여 준 뒤, 그 도구를 업데이트할지 나에게 한 번에 하나씩 물어봐. 내가 동의한 경우에만 업데이트해.
   - Codex CLI의 공식 설치 방법에 Node.js 같은 선행 도구가 필요하고 그 도구가 없다면, 왜 필요한지 설명하고 설치해도 되는지 먼저 물어봐. 내가 동의하면 공식 Windows 패키지로만 설치해.
   - 설치나 업데이트 뒤에는 필요한 경우 새 PowerShell 세션에서 다시 명령을 확인해. PATH 반영을 위해 재시작이나 새 터미널이 필요하면 그 사실을 설명하고 내게 필요한 행동을 한 가지씩 안내해.

4. 세 도구가 모두 실행 가능해지면 Git 전역 사용자 설정을 확인해.
   - `git config --global user.name`과 `git config --global user.email`을 확인해.
   - 기존 값이 있으면 값 자체를 과도하게 노출하지 말고, 설정되어 있다는 사실과 변경 여부를 물어봐.
   - 이름과 이메일은 각각 한 번에 하나씩 물어보고, 내가 답한 값으로만 `git config --global user.name`과 `git config --global user.email`을 설정해.
   - 이메일 형식이 명백히 잘못된 경우에만 이유를 설명하고 같은 항목을 다시 물어봐.

5. GitHub CLI 인증 상태를 `gh auth status`로 확인해.
   - 이미 로그인되어 있으면 기존 로그인을 유지하고 다음 단계로 가.
   - 로그인되어 있지 않으면 `gh auth login`으로 GitHub.com, HTTPS, 브라우저 로그인 방식을 사용해. 브라우저나 코드 입력 화면이 열리면 내가 직접 완료할 때까지 기다려. 인증 정보를 묻거나 대신 입력하지 마.
   - 내가 완료했다고 말하면 `gh auth status`로 상태를 다시 확인해.

6. 마지막으로 아래 항목을 직접 실행해 모두 확인하고, 결과를 표가 아닌 짧은 목록으로 요약해.
   - `codex --version`
   - `git --version`
   - `gh --version`
   - `git config --global user.name`
   - `git config --global user.email`
   - `gh auth status`

완료되지 않은 항목이 있으면 성공한 항목은 그대로 두고, 실패한 항목·원인·다음에 내가 해야 할 한 가지 행동만 쉬운 말로 알려 줘. 완료되면 Codex CLI, Git, GitHub CLI가 준비되었다고 알려 주고, 다음에 GitHub 저장소를 만들거나 기존 프로젝트를 내려받을 수 있다고 짧게 안내해.
```

## 포함된 도구

- Codex CLI
- Git for Windows
- GitHub CLI

프롬프트는 기존 설치와 설정을 먼저 확인하므로, 이미 설치된 도구를 불필요하게 다시 설치하지 않습니다.
